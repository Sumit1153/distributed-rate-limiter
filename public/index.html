03 · UNDER THE HOOD

Four strategies. One gateway.

Redis executes each check as a single atomic Lua script. If Redis cannot be reached, the service continues in explicitly labeled per-instance fallback mode.

01

Token Bucket

Refill tokens at a steady rate. Short bursts are accepted until tokens run out.

02

Fixed Window

Count requests within discrete windows. Boundary bursts can occur.

03

Sliding Window

Count requests in the preceding rolling interval using a sorted set.

04

Leaky Bucket

Drain accumulated usage over time; reject when full. No request queue.
